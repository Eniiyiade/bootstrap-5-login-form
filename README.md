# Bootstrap 5 Login Form

This is a simple and responsive login form built with HTML, CSS and Bootstrap 5.

## Files
- `index.html` - contains the login form structure.
- `style.css` - contains the extra styling for the page.

## How to view the project
1. Download or extract the project folder.
2. Open `index.html` in a web browser.
3. Make sure you have an internet connection so the Bootstrap 5 CDN can load.

## Features
- Email and password fields
- Remember me checkbox
- Forgot password link
- Login button
- Sign-up link
- Responsive Bootstrap layout

Note: This is a front-end assignment demo. It displays a login form but does not connect to a database or authenticate users.
